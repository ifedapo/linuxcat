# LinuxCat 🐧

## Linux Server Deployment and Cloud Infrastructure Project

LinuxCat is a hands-on Linux administration and cloud infrastructure
project documenting the deployment and configuration of an Ubuntu
server on AWS EC2.

🌐 **Live Website:** https://linuxcat.site

## Technologies Used

- Ubuntu Server
- Amazon Web Services (AWS EC2)
- Nginx
- Apache2
- BIND9
- DNS
- SSH / ED25519
- Namecheap
- Let's Encrypt / Certbot
- Git and GitHub

## Project Objectives

1. Deploy an Ubuntu Linux server on AWS EC2.
2. Configure secure SSH remote access.
3. Allocate and configure an AWS Elastic IP.
4. Connect a registered domain to the Linux server.
5. Understand DNS records and DNS resolution.
6. Investigate authoritative DNS using BIND9.
7. Configure Nginx for website hosting.
8. Configure HTTPS using Let's Encrypt.
9. Monitor Linux server activity and access logs.
10. Monitor AWS infrastructure costs.

## Architecture

Internet → Namecheap DNS → AWS Elastic IP
→ AWS EC2 Ubuntu → Nginx → LinuxCat Website
